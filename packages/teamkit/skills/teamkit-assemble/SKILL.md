whenToUse: 准备开一个新团队；或给现有团队加人/撤人/换分工之前。

# 建队（照着填，别即兴）

## 0. 先过三道闸（任何一道不过就别开队）
| 闸 | 问自己 | 不过就 |
|---|---|---|
| **必要性** | 这件事需要一个"跨多轮记得住、能被追问"的负责人吗？ | 用 workflow / 单个 `subagent` |
| **判据** | 能写出**可观察**的完成判据吗（文件存在 / 命令输出 / 读数）？ | 活还没想清，先别开人 |
| **交付** | 有一份**要落盘的产物**吗？ | 纯讨论别开队，自己说完 |

## 1. 产出物：先写编制，再开人
照 `ROSTER.yml` 填：`objective` / `done_when[]`（可观察）/ `gate` / `budgets`（`max_tiers`、`per_line_rounds`、`global_stop`）/ `lines[]`。
**写不出 `done_when` 就是第 0 步没过。**

## 2. 切单元（对应 OMC 的 accountable unit）
一个单元 = **一次能被独立评审的交付**。每个单元必须有四样：

| 要素 | 要求 | 反例 |
|---|---|---|
| `owner` | 唯一归属（DSH 成员制天然保证） | "大家一起弄" |
| `acceptance_criteria` | **可观察**，**不许为空** | "做好了" |
| `write_scope` | 预计会碰的文件前缀 | 不写，事后靠猜 |
| `blocked_by` | 只允许"上游→下游"，**无环** | 互相等 |

- **粒度判据**：小到能一次评完，大到值得一次评。太碎 → 沟通成本吃掉收益；太大 → 评审只能盖章。
- 判据为空 = 无法评审。**原版 OMC 允许空判据（只因代码查了字段在不在）；我们也不拦** ——
  ⚠️ **更正（2026-09-14 / Round 86 实测）**：本条原先写的是「**我们不**」——
  **那是空头承诺**。实测：`team_task_create` 的参数 schema **只有 `subject` / `description` /
  `blockedBy` / `writeScopes`**，**根本没有 `acceptance_criteria` 这个字段**；
  而本插件的代码里**一行都没查过它**（`grep acceptance_criteria plugin/**` = 0 命中）。
  ⇒ 真相是：**这一条靠你自己守**（跟原版一样），**不是机制**。
  写进哪个字段？—— 写进 `description`（评审时看它）。
  ⇒ **判据**：凡是这个技能里"在代码里真会拒"的，都写成「**`<工具>` 会直接报错**」；
    **没写的，就是协议**（靠自觉）。**不许把"我们要求"说成"我们强制"。**
- 依赖环：`team_task_create` 建边时会检环，**检测到直接报错** —— 遇到就当场拆（把环上最小那块合并给一个 owner）。
  ✅ **这一条是真的机制**（与上一条不同：底座源码里确有环检测）——
  本技能里"真机制"与"纯协议"的**唯一分别就是这一句有没有**。

## 3. 选人（Talent Market 的手工版）
**先查索引，别凭印象挑人**：打开 `$DSH_HOME/teamkit/TALENTS.yml`（= 原版 `search_candidates` 的手工等价物），
按 `role` / `skills` / `use_when` 过滤 → 读 `$DSH_HOME/teamkit/talents/<file>` → 用它的 `acceptance_style` 与 `write_scope` 派活。
> ⚠️ **`<DSH>` = `$DSH_HOME`（没设 = `~/.dsh`）**；**别按仓内相对路径拼** ——
>   装出来的资产在 `$DSH_HOME/teamkit/`，**不在你当前项目里**（我实测踩过：拼错的那份**不会被读**，见 `teamkit-a2a`）。

| 缺什么 | 怎么办 |
|---|---|
| 缺**技能** | 现写一份 Talent（按 `$DSH_HOME/teamkit/talents/_SPEC.md` 的字段）落盘，**并把它注册进 `$DSH_HOME/teamkit/TALENTS.yml`** —— 下次它就是这个组织的一部分 |
| 缺**判断** | 这活该你自己（Lead）干，别外包 |
| 缺的只是**一次性算力** | 用 `subagent`，**不要** `spawn_teammate` |

**优先复用**：现编的身份下次就找不回来。索引里找不到合适的，先问"是不是我把活切错了"。

## 4. 定层（默认 2）
| 情况 | 层数 |
|---|---|
| 1 人能干（含自己） | 0 —— 别开团队 |
| 有并行块 + 一个持续负责人 | **2**（负责人 + 执行者） |
| 多条线各自有大块活、负责人自己管不过来 | 3（每条线一个主管） |
| ≥ 4 | **不要**：改分批，或整条线外包给一个负责人 |

**每加一层必须写清这一层唯一的职责**；写不出来就是纯开销，撤掉。
`coo` = 跨线裁决 + 改切分 + 汇总证据；`chief` = 对外口径 + 最终裁决 + 什么时候停。

## 5. 铺板（`team_task_create` 字段对照）
| 你要表达的东西 | 写到哪 |
|---|---|
| 单元标题 | `subject` |
| **原始目标原话** + 完成判据 + 写范围 + 不准碰什么 | `description`（**DSH 没有独立的判据字段，判据写进 description**，用固定小标题分段） |
| 依赖 | `blocked_by` —— 必须用**已建出来的** task id |
| 写范围 | `write_scopes` —— **advisory**：只发重叠 warning，不锁 |

`description` 的推荐骨架：
```
目标（原话）：<客户/Lead 的原话，不要只留你的转述>
完成判据：
- <可观察 1>
- <可观察 2>
写范围：<前缀>    不准碰：<...>
上岗材料：<文件路径>（先读；首次回报请带上暗号）
```

⚠️ **DSH 实测两个坑**：
1. **就绪不会自动开工** —— `ready` 只是"pending 且所有 blocker 恰好 completed"，板**不会自己推**；你必须显式唤醒（`send_message`）。
2. **成员退出不释放 owner** —— 会留下僵尸 `in_progress` 任务，只有 Lead `reassign` 能收。
   ⇒ **要撤人先搬活**：`reassign` 完再释放；撤人的工具与三条约束见 `teamkit-escalate`「撤人怎么撤」。

## 6. 开人（`spawn_teammate` 的提示词只放四样）
1. **身份**：Talent 名 + 一句话职责；
2. **完成判据**：逐条抄 ROSTER 里的可观察判据；
3. **写范围 + 不能碰什么**（抄 Talent 的 `write_scope`）；
4. **上岗材料**：一份**现造的、落盘的文件路径**，让它先读 —— 而不是把上下文塞进提示词。
   材料三件套：`$DSH_HOME/teamkit/talents/<name>.md`（它是谁）+ `$DSH_HOME/teamkit/talents/principles/<name>.md`（**它的工作原则，若已存在**）+ 本次任务卡。
   > **暗号法**：材料里放一个只有真的读过才知道的值（如 `暗号：K7-axolotl`），要求它首次回报时带回。
   > 这是"真读到"的**唯一**证据；没有暗号，你无法区分"读了"和"猜的"。
   > 原版是靠 `execute_hire()` **全程确定性、不调模型**地灌注上岗材料的
> （`onboarding.py:867-1122`；⚠️ **原先这里写的是"23 步"—— 那个数是我编的、数不出来，R88 已更正**）；
> DSH 没有这一步，**只能你手工造**。

**治理规则先读**：`$DSH_HOME/teamkit/RULES.yml`（必须上报的四类、never 清单、下游交接、成本阀）。
把它的一句摘要放进提示词（例：*"要花钱/动生产/对外发布，先上报；不许覆盖别人的产物"*）。

## 7. 运行中调整（这就是"自组织"）
- **不足则加**：某条线反复卡在同一类问题 → 现写一份专精 Talent 招进来，**不是**让原人加班。
- **冗余则撤**：连着两轮没有可验证产出 → 撤掉，活收回上层。
- **换法优先于换人**：先改判据或改切分；同一个切分换人通常没用。
- 每次调整写一句「为什么」并落盘 —— 这是复盘时唯一能救你的东西。

## 8. 开完就能验收（三条，缺一条就是没开好）
- [ ] 每个人都真上岗：`list_agents` 看得到，roster 里对得上；
- [ ] 板上每个任务都带**判据**与**依赖**（判据在 `description` 里，且非空）；
- [ ] 上岗材料**在盘上**，且至少有一次回报把**暗号**带回来了。
