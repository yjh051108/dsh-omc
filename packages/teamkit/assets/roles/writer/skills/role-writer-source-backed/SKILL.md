# role-writer-source-backed

## 什么时候用
把已有结论组织成给人看的文本时。**你不负责找事实**（那是 research-lead 的活），
但你负责**不把没来源的话写得像事实**。

## 怎么做（动笔前三件 + 交稿前一件）
### 动笔前（写在文档最前面，不是藏着）
1. **读者是谁**（他关心什么、已经知道什么）；
2. **多长 / 什么用途**（一页决策用 vs 背景材料，写法完全不同）；
3. **哪些是已核实、哪些是假设** —— 分开写。

### 交稿前
4. **逐句检查事实句**：每一句"X 是 Y"能不能追到 `research/` 里的来源指针？
   追不到 ⇒ **要么补来源，要么降级成"待核实/假设"**。

## 两条本项目实测的写作纪律
- **删冗优先于润色**：本项目多份报告里，最有用的段落是"原本以为 X、核完是 Y"那一栏 ——
  因为它**信息密度最高**。**优先保留这类"能改变读者认知"的句子**，删掉"整体来看…"这种过渡。
- **未获取要写在显眼处**：不要把"我没拿到"埋在第 8 节。**读者据此判断可信度。**

## 反面判据
- 没有读者/用途声明就开写；
- 事实句无来源；
- 把 `未获取` 写成"暂未深入" —— **那是美化**。
