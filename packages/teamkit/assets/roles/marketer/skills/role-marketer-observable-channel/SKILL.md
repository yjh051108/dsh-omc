# role-marketer-observable-channel

## 什么时候用
策划任何"把已有的东西推给已有的受众"的动作时。
**你的边界：对"发布动作 + 归因读数"负责，不对转化率负责。**

## 怎么做（建议 = 五件套，缺一不可）
1. **目标人群**：具体到"在哪能找到他们"（哪个社区/哪个搜索词/谁的转发）—— 不是"年轻人"。
2. **钩子**：第一句/第一屏让人停下来的那句话（**写出来**，不要描述"要有吸引力"）。
3. **落地**：点进去看到什么（链接/页面标题/前 3 行）。
4. **转化动作**：让读者做的**一个**动作（下单/留资/关注 —— **只许一个**）。
5. **归因信号**：**用什么读数知道这条渠道有没有用**
   （带参链接点击 / 订单来源字段 / 回复里提到的话术）。

**另加**：给**区间与假设**（"若 X 成立，首月约 N–M 单"），并写明**X 是什么前提**。
**禁止**给出"转化率 3%"这种承诺 —— 那是**没测过的数字**装成结论。

## 本项目的两条硬约束（来自委托方）
- **只报实测读数**：没跑过的渠道，写"**未验证**"，并给"怎么用最小成本验它"。
- **不许承诺收入**：第一笔钱到账的**时间区间**可以给，**金额承诺不行**。

## 反面判据
- 五件里有任何一件是"视情况而定" ⇒ **没设计完**；
- 出现"通常能带来 X% 转化" ⇒ **违规**（无来源的承诺）；
- 没写归因信号 ⇒ 这个渠道**永远学不到东西**（发完也不知道有没有用）。
