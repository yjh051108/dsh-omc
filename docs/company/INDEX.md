# docs/company —— 索引（**先读这个**）

> **这是「读的东西」** —— 这家公司**为什么长这样 · 怎么开 · 怎么运营 · 怎么复盘**。

> ★ 本文件是**索引**（2026-09-18 新增 · 归 `monorepo-overlay/`）。
> ⚠️ **它不是从上游搬来的** ⇒ `monorepo-assemble.mjs` **不会覆盖它**
> （判据：跑一次 `--assemble` **两次**后，本文件仍在）。

## 一 · 先读顺序（**照本仓根 `AGENTS.md` 那份的形态**）

```
① 【先懂为什么】      → WHY.md            （马克思主义推出的 AI 公司形态）
② 【再懂怎么开】      → BUILD.md          （装 → 第一支队 → 第一件活）
③ 【然后避免卡死】    → RUN.md            （评审门 · 依赖 · 重启后怎么续）
④ 【怎么验我照做了】  → CRITERIA.md       （每条结论 → 一条能当场回答的判据）
⑤ 【开始前先看坑】    → LANDMINES.md      （★ 最贵的两份之一）
⑥ 【装不上/装了没反应】→ INSTALL-PITFALLS.md（两类死法 + 机械检查）
```
⇒ **读完 ①–④ 就能开一家能跑的公司**；⑤⑥ 是**开始之后**才需要的（**而先看能省你一次事故**）。
