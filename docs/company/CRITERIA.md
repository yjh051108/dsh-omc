# 判据对照表 —— 每条结论 → 一条能当场回答的判据

> **这份文档存在的唯一理由**：**证明上面那些理论不是读后感。**
> 判据的验收标准有两条：① **能在一次真会话里被回答**（不是格言）② **答"不"的时候有事发生**（能红）。

---

## 用法（**先看这一段**）

```
① 找到你要做的动作（左栏"什么时候用"）
② 读它的判据句（中间那栏）—— ★ **那是一句可以直接问出口的话**
③ 按右栏的"答'不'怎么办"处理
```
⚠️ **判据句的共同形状**：**问一个"是/否"或"哪一个"的问题**。
**若你问出来的是一句"要有责任心"这类话 ⇒ 那不是判据**（它答不出"是/否"）。

## 一 · 从「上下文 = 生产力」推出来的

| # | 结论（来自 `WHY.md` §1） | 判据（**能当场回答**） | 答"不"怎么办 |
|---|---|---|---|
| **K1** | 占用上下文却不产生价值 = 浪费生产力 | **「这个动作产出什么可交付物？」**（文件 / 读数 / 通过的判据 / 别人能用的东西） | **不做**（或先搞清楚为什么要做） |
| **K2** | 上下文占用有贵贱（管理者的最贵） | **「它占用谁的上下文？占用管理者的是不是可以换给别人？」** | 换执行者做，或降级 |
| **K3** | 上下文是瓶颈 ⇒ 谁成为关键路径谁就该让位 | **「这件事卡在谁身上？那个人是不是唯一的？他不在，别人能不能推进？」** | 立刻补第二人 / 把判据写下来 |

**现场（K1 真被用过）**：本公司协调台账因此加了一列「产出」——
**没有可交付物的条目不许进台账**。这不是建议，是**录入规则**。

## 二 · 从「AI 与人错配方向相反」推出来的

| # | 结论（`WHY.md` §2） | 判据 | 答"不"怎么办 |
|---|---|---|---|
| **K4** | 制度应"减负"不是"加锁" | **「这条规矩减少了谁的哪一步人工动作？」** | 答不出 ⇒ **它大概率是成本**，先别加 |
| **K5** | 先问"能不能不做" | **「这件事不做，会怎样？」**（要具体说出一条后果） | 说不出来 ⇒ **不做** |
| **K6** | 纪律只有两种形态：断言 / 备忘 | **「这条规矩会红在哪？红了之后谁会看到？」** | 答不出 ⇒ **当场标"备忘"**，**不许冒充机制** |
| **K7** | 只有 1 次事故 ⇒ 先不加规矩 | **「我没加这条规矩之前，出过几次这个问题？」** | **只有 1 次 ⇒ 先不加**（先观察） |

**K6 的现场**：本公司那条"管理者不再动手"的自我约束 ——
**它写在成文法里，一次都没拦住人**；真正拦住人的是**自动断言**与**宿主硬拦**。
⇒ 所以它现在被**明确标为"备忘"**，并在复盘中要求**转成断言或删掉**。

## 四 · 从「实践是检验真理的唯一标准」推出来的

| # | 结论（`WHY.md` §4） | 判据 | 答"不"怎么办 |
|---|---|---|---|
| **K11** | 只报实测读数 | **「这个数是跑出来的，还是我觉得的？」** | 说不清 ⇒ **写「未获取」**，不许写"应该没问题" |
| **K12** | 报"零/没有"要附搜索范围 | **「我搜了哪些词、哪些目录？」** | 答不出 ⇒ **那个"零"不成立**（重搜） |
| **K13** | 断言必须能红 | **「把被测对象弄坏，它会报红吗？红在哪一行？」** | 答不出 ⇒ **那不是判据** |
| **K14** | 判据会腐坏（判据通胀） | **「这条判据里的真值，现在还是真的吗？」**（拿真值回验一次） | 过期 ⇒ **改成动态读真值**，否则它必然报红 |
| **K15** | 复盘必须至少一条"减少人工动作" | **「这次复盘的行动项里，哪一条让人少做一个动作？」** | 答不出 ⇒ **不算合格复盘** |

**K14 的现场**：有条判据把人数**写死成 16**，而编制已到 **22** ⇒
**该判据必然报红，而没人知道它在说谎** ⇒ 这就是"判据通胀"，
**正解是改成"现算真值"**（同一个真值只算一处）。

## 七之二 · 元判据（**判据自己的判据** —— 三条，都是被事故打出来的）

> 这三条不判"事情做得好不好"，判**"你手上那套判据本身靠不靠得住"**。
> 它们**都不是想出来的**，是**三次真事故**各自留下的疤。

### K23 · ★★ 「报"没有"之前，先证明"我搜够了"」

```
【判据句】我要说"X 不存在 / 没有命中 / 未获取" ⇒
          ★ 我能不能贴出：**我搜了哪些地方** + **命令原文** + **退出码/输出行数**？
          ★ 而这些范围**覆盖了 X 本该在的每一个位置**吗？
【答"不"怎么办】⇒ ★ **不许说"没有"** ⇒ 改说「**未获取**」+ 附**已搜范围**。
【现场（真事）】写 `check-profile-bundles.mjs` 时，第一版只搜
  `profile/node_modules` 与 `$DSH_HOME/node_modules`
  ⇒ `@deepseek-ai/dsh-base` / `dsh-web-app` 报「**未获取**」—— 而它们**确实存在**（在**宿主安装树**里）
  ⇒ 补上候选路径后：**未获取 = 0**。
★ **机械形态**：那个数字（`未获取 N`）**本身就是探针** —— 它不为 0，先怀疑"我搜窄了"。
```

### K24 · ★★ 「保留历史的方式，不许让已废止的词重新出现在全文命中里」

```
【判据句】我要"保留一段历史"时 ⇒ ★ 我保留的做法，**会不会让那个已废止的词
          在机械判据（grep）里**再次命中？
【答"不"怎么办】⇒ ★ **用不带那个词的表述承载同样的历史**（**不是改判据去迁就文案**）。
【现场（真事）】`plugin/README.md` 里有一条已过期的"正在另起实验探究…"。
  第一版我把它**划掉（~~…~~）保留作对照** ⇒ 但**机械判据查的就是那个词** ⇒ 全文命中 2 ⇒ 判据红。
  ⇒ 改成：「早期是"待探究"，现在是可以」+「别处若见"此项待探究"，那是过期表述，以本节为准」
  ⇒ 命中 **0**，而历史**照样留住了**（还更清楚：点明了"从不能到能"本身是成果）。
★ **为什么它可复用**：**任何"要留档"的文档，都会和"要机械可查"打架** ——
  而正解**永远**在**表述侧**，不在判据侧（改判据去迁就文案 = 把闸调松，是本末倒置）。
```

### K25 · ★★★ 「新判据做出来了 ⇒ 必须同时证明【谁会跑它】」

```
【判据句】我新增一个 `tools/check-*.mjs` / `verify-*.mjs` / 任何测试件 ⇒
          ★ **贴出"它被谁调用"**（`check-all` 里的引用行 / 别的机械调用点）；
          若一个都没有 ⇒ **它等于不存在**。
【答"不"怎么办】⇒ ★ **当场接进 `check-all`**（或写明"它是被 X 调用的"）⇒ **否则不许算完成**。
【现场（真事，同一族踩了三次）】
  · ★ 第一次：`check-all` **被造出来的原因**就是它——7 个校验器**一个都没被谁调用过**
    （它自己的注释逐字写着：「全靠我'记得跑' ⇒ 漏跑一条不会有任何信号」）
  · ★ 第二次：`crash-guard-uncaught-test.mjs` 写完当天，`check-all` 里**引用 = 0** ⇒
    **刚做出来的双向判据，没有任何机械动作会跑它**
  · ★ 第三次：`check-profile-bundles.mjs`（同类风险 —— 靠"我接了"而不是"检查它接了没"）
★ **为什么它是最要紧的一条**：**前面两条判的是"读数对不对"，这一条判的是"读数会不会被读"** ——
  而**一个永远不会跑的判据，比没有判据更坏**（它给人"已核过"的错觉）。
  ⚠️ 这也正是本项目最反复那一族的**自指版本**：**把"有机制的样子"当成机制**。
```

### K26 · ★★ 「读退出码时，那个码有没有被中间环节改掉？」

```
【判据句】我要拿退出码当下结论（"它拒绝了"/"它成功了"）⇒
          ★ 我这条命令**有没有接管道 / 重定向**？那个 `$LASTEXITCODE` 是
          **我要的那个进程**的，还是**管道末端**那个的？
【答"不"怎么办】⇒ ★ **要读退出码就别接管道**：
            `& node x.mjs *> file; $LASTEXITCODE`（先读码，再 `Get-Content file`）
【现场（真事，两人各踩一次）】
  · CEO：`node tools/push-all-via-api.mjs … | Select-Object -First 1` ⇒ 读到 **0**
    ⇒ ★ **他一度以为"拒绝但退出码是 0"（判据不硬）** —— 而不接管道 ⇒ **真实 exit=2** ✅
  · 同族：`release-push` 的 R5 第一版把 **"取不到"** 当成 **"443 仍被占"** ⇒ **假红**
    （两个不同的中间环节，同一个错：**读数被换掉了而我没察觉**）
```
> ★ **它属于 `R23` 家族**（"读数被中间环节改掉"），但**独列一条** ——
> 因为**它不报错**：管道**静默地**把退出码换成了末端命令的码，**你看不出任何异常**。
