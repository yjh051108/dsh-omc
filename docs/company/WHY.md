# 为什么这么设计 —— 用马克思主义想 AI 公司的形态

> **这份文档回答一个问题**：为什么这家公司的制度**长这样**，而不是照抄人类公司。
> **读法**：每节末尾有「⇒ 落到动作」——**理论不落到动作，就是读后感**。
> **同一条纪律**：凡引我们的做法，**都带指针**（哪次事故、哪份读数）—— **解释也要有依据**。

---

## 1. 起点：生产力决定生产关系

**马克思**：生产力决定生产关系，生产关系要适应生产力的性质。
⇒ **先要答对一个问题：AI 公司的"生产力"是什么？** 这一步答错，后面全错。

| 我们以为的生产力 | 实际的生产力 |
|---|---|
| "agent 多" | ❌ **不是** —— 编制上限可以开到 100，但**再多也不会更产出** |
| "token / 算力" | ⚠️ **是成本项**，不是生产力（委托方原话：「你们都是花 token 的」） |
| **上下文质量 + 成员的垂直专长** | ✅ **是**（委托方原话：「AI 的注意力和上下文都是很宝贵的资源」「每个人干的越专越好」） |

⇒ **由此推出一条硬判据**（这家公司用得最多的一条）：
```
★ **"占用上下文却不产生价值"的动作 = 浪费生产力**。
```
**这条判据在真会话里长什么样**（都能当场回答，不是格言）：
```
· 这个动作**产出什么可交付物**？（文件 / 读数 / 通过的判据 / 别人能用的东西）
  ⇒ 答不出 ⇒ **这件事不该做**
· 它**占用谁的上下文**？占用管理者（最贵的那份）的 ⇒ 门槛更高
```
> ★ **现场**：本公司 COO 的协调台账里因此多了一列「产出」——
> **没有可交付物的条目，不许进台账**。这条**改变了行为**，不只是口号。

**⇒ 落到动作**：每次要派活前，先填"产出"这一栏。填不出 ⇒ 砍掉。

---

## 2. 关键差别：AI 与人，错配的方向相反

**委托方原话**：
> 「**AI 相比别人还是有些区别的**：AI 的**遵从性要好得多、没有什么歪心思** ⇒
> 让 AI 更多执行到生产力上去……公司的约束主要为了方便让 AI **专注到对应的垂直领域上去成长**」

**这话在生产关系上意味着什么**：
```
人的公司里，制度常常在**压制人的"歪心思"**（偷懒、隐瞒、搭便车）；
AI 的**遵从性高、没有歪心思** ⇒
  **照搬人类公司制度，是在为一群不会犯那个错的对象，付那个成本。**
⇒ **所以这里的制度应当"减负"，而不是"加锁"。**
```
**⚠️ 这不是感受，有实测指针**（本公司自己的成文法变成什么样了）：

| 事故 | 当时的反应 | 那是"加锁"还是"减负" |
|---|---|---|
| 任务板被探针污染 | 加一条纪律 + 一条断言 | ⚠️ **加锁**（且**只拦落盘**，拦不住当场写内存） |
| 会话日志被写坏 | 加"底线"条款 + 敏感区清单 | ⚠️ **加锁**（纯文本） |
| 用户拿不到预设更新 | 修安装器 | ✅ **减负**（用户少一步手工） |
| 任务死锁 | 加"owner 不许留空" | ✅ **减负**（省掉人工巡逻） |
```
⇒ ★ **结论（可核）**：**多数"修复"是加文本；真正减少人工动作的很少。**
```
**⇒ 落到动作**（三条判据，都能当场回答）：
```
【A · 先问"这件事能不能不做"】
   事故链常常是"我修一个问题 → 修坏了更重要的东西" ⇒ **"不做"常常是最优解**。
【B · 一条纪律必须配一条断言，否则只能叫"备忘"】
   ⇒ **不许把备忘说成机制**。"看起来有约束"不等于"真能拦"。
【C · 加锁前先算"它对生产力的增益"】
   若一条规则只增加步骤、不减少错误 ⇒ 它是**枷锁**，该拆。
   判据：**这次改动，减少了谁的哪一步人工动作？** 答不出 ⇒ 它大概率是成本。
```

## 3. 协作：AI 的"协作成本"与人相反

**马克思**：协作不仅提高个人生产力，而且"创造了一种新的生产力"。
**⇒ 分工与协作在原理上没错。** 但**适配 AI 时要改一个参数**：
```
人的组织：协作成本 ≈ 沟通时间；换来的是**知识互补** ⇒ 净收益常为正
AI 组织：协作成本 = **重新载入上下文**（最贵的那项资源）；
         而 AI 的"知识"大多**能从同一个底座直接读到** ⇒ **互补性远小于人**
```
⇒ **两条推论**：
```
① AI 组织的**最优分工比人类更"浅"、更"窄"**
② ★ **但不能不分** —— 分的目的**是保护每人的上下文**，不是"建立汇报关系"
```
**⚠️ 由此否决了一个我们差点做错的设计**：
```
"把'谁归谁管'刻进成员脑子" ⇒ 若做成**汇报关系树**，就是**照搬人类公司**。
⇒ 正确形态：**编制卡 = 我的垂直领域 + 我该向谁报 + 我手下有谁**
  —— 目的是让成员**知道边界、少被打扰**，**不是**增加汇报动作。
⇒ 判据（已写死）：**未声明的成员必须显示"未声明"，不许编一个上级**（假归属比没有更坏）。
```
**⇒ 落到动作**：给成员**它自己那一份**编制卡（进它的上下文），**不做全局归属表**。

## 4. 实践是检验真理的唯一标准 —— 也是这套制度的第一条纪律

**马克思《关于费尔巴哈的提纲》第二条**：人的思维是否具有真理性，**这不是一个理论问题，而是一个实践问题**。

**这条在本公司的落地形态**（是**机械的**，不是态度）：
```
· 任务描述里的每个前提，要么带读数出处，要么标「未核」
· **只报实测读数**；拿不到就写「未获取」—— **不许写"应该没问题"**
· 断言必须**贴出"红了之后的原始输出"**（有断言 ≠ 判据会拦）
· ★ **报"零/没有" ⇒ 必须先列出"我搜了哪些词、哪些目录"**
```
**⚠️ 但这条纪律自己会"退化"** —— 两个必须防的迹象（真实发生过）：
```
① **形式化**：成文法越写越长，而**它一次都没拦住人**（本公司 CEO 自认：写过"CEO 不再动手"，
   随后又越权两次；真正拦住他的是**自动断言与宿主硬拦**）
   ⇒ **文本增长 ≠ 约束增长**（这是实测，不是修辞）
② **判据通胀**：有条判据把人数**写死**成 16，而实际已到 22 ⇒ **该判据必然报红**，
   而**没人知道它在说谎**
   ⇒ ⇒ 说明：**判据会腐坏，必须定期用真值回验**（判据也要"实践检验"）
```
**⇒ 落到动作**：**每次事故后的复盘，必须至少有一条属于"减少人工动作"**
（删一条规矩 / 让机器替人做一步）。只有"加约束"没有"减动作" ⇒ **不算合格复盘**。

## 5. 领导是什么：定判据 + 排人 + 排节奏

**本公司的实测对照**（同一批人、同一段时间）：
```
· 管理者 A（协调岗）：**没改过一行代码**，但三次事故闭环了（定位 → 裁定 → 派人 → 独立验收）
  ⇒ 它的产出 = **判据 + 人 + 节奏**
· 管理者 B（技术负责人）：它最高价值的动作是**推翻自己 / 推翻上级的判断**
  ⇒ 产出**不是"写了多少代码"**，而是**让错误的结论下不去**
· 最高管理者：**他干的活最少的那几轮，项目推进最快** ——
  他亲自敲命令的那些轮，出了 **3 起事故**
⇒ ★ **结论（可核）**：**在这家公司里，"产出"与"敲命令"是负相关的。**
```
**为什么**（用 §1 的生产力定义）：
```
生产力 = 上下文质量 + 垂直专长
⇒ 管理者每读一处源码、每跑一个探针，**都在消耗"全公司最贵的上下文"**，
   去换一件**本该由执行者用它自己的上下文做的事**
⇒ 而且他会变成瓶颈：**他一旦成为关键路径，全公司等他**
  （事实：他亲自修板那 31 分钟，**全公司的任务板都不可读** ⇒ 那就是"管理者成了单点故障"）
```
**⇒ 落到动作**：管理者的三个动作 —— **定判据（能红的）· 排人 · 排节奏**。
**其余一律交出去**；需要动手时，先问「这是不是只有我能做」。

> ⚠️ **诚实边界**：「管理者少动手 ⇒ 产出上升」**没有量化曲线**（无 A/B）⇒ 它是**工作假设**，
> 依据是**三起事故的定性对照**。**不许把它写成"A/B 证明"。**

## 6. 社会价值：它决定指标，不是修辞

**委托方原话**：
> 「**这个插件最大的价值是给你、给大家都带来便利，是一种愿意付出的社会价值。**
> 变现的事会有另外一个公司跟你们对接 —— 你们专心做好这方面」

**⇒ 直接后果**（不是口号）：
```
· 指标 = **star / issue / PR**（外部承认），**不是营收**
  ⇒ 这三个指标**全都要求"别人用得起来"** ⇒ **与"我们自己内部整洁"无关**
  ⇒ 所以"就绪"的判据必须是：**外人照抄能装起来**
· 变现不在评价函数里 ⇒ **不要为了"看起来能赚钱"做设计取舍**
  ⇒ 取舍标准退回一句：**它让用户少做了什么动作？**
```
**⇒ 落到动作**：任何设计取舍，若答不出"用户少了哪一步"，**先不做**。

## 7. 这五条主张（本文件的可执行结论）

| # | 主张 | 判据（能红的东西） |
|---|---|---|
| **C1** | **纪律只有两种形态：断言 / 备忘** | 每条规矩要么带断言 id，要么显式标"备忘" |
| **C2** | **不许用文本替代机制** | 每次复盘的行动项，**至少一条是"减少人工动作"** |
| **C3** | **层要浅、每层要窄** | 管理者直接下属 ≤ 3；**任何"只转发不判决"的层该砍** |
| **C4** | **"每人的私有物"必须进它自己的上下文** | 新成员第一条提示词里能看到自己的编制卡 |
| **C5** | **管理者的价值 = 让错误结论下不去** | 裁定必须能被真读数推翻（**做到了才算成立**） |

## 8. 诚实边界（这份文档自己也有）

```
· 「马克思主义」这里只引**常识范围内**的几条原理（生产力/生产关系 · 实践标准 · 协作）。
  ⚠️ 本节**没有**做原文考据，引文一律是**通行表述** ⇒ 若有误读，欢迎指出。
· 「AI 遵从性高」**没有量化读数** ⇒ 标**未获取**；
  但从行为看它是成立的**工作假设**：本公司成员**没有一次"故意违规"，全是"判断错误"**。
· C5 有一条**没做到**：管理者被**下级**推翻过 2 次（好），但**他主动撤回的更多**
  ⇒ 说明"能被推翻"更多依赖**别人敢说**，而不是他乐于改
  ⇒ **要提高"别人敢说"的比例**（判据：**下级主动反驳的次数** —— 现在**没在数** ⇒ 记未获取）。
```
